## 一、全局服务启动参数（8 个模型通用，`run_list.py`）

每张卡实际起的命令等价于：

```bash
vllm serve <model_path> \
  --trust-remote-code \
  --gpu-memory-utilization 0.8 \
  --served-model-name <served_name> \
  --block-size 64 \
  --tensor-parallel-size 1 \
  --pipeline-parallel-size 1 \
  --port <8000+idx> \
  --compilation-config '{"cudagraph_capture_sizes":[1,2,3,4,5,6,7,8,10,12,14,16,18,20,24,28,30,32,50,64,100,128,256]}' \
  <该模型的 extra_args>
```

| 项 | 值 |
|---|---|
| TP / PP | 1 / 1（单卡一模型） |
| GPU 显存占用 | 0.8 |
| block-size | 64 |
| 端口 | 8000–8007 |
| 引擎 | V1（`VLLM_USE_V1=0` 是死代码，本版本已无 V0，实际跑 V1） |
| 默认开启 | prefix caching、chunked prefill（V1 默认值） |

## 五、相比原交接脚本的参数修改

原版（备份在 `_orig_backup_20260528/`）是：**一套固定 rate 序列（18 cases）套到 8 个 Qwen3-VL 模型**，无并发/投机调参。逐项对照：

### 5.1 测试对象（模型清单）

| | 原版 | 本次 |
|---|---|---|
| 模型系列 | Qwen3-**VL**（视觉多模态）8 个 | Qwen3 / Qwen3.5 **文本**模型 8 个 |
| 具体 | Qwen3-8B、8B-FP8、VL-2B/2B-FP8/4B/4B-FP8/8B/8B-FP8 | Qwen3-8B(BF16/FP8)、14B(BF16/FP8)、Qwen3.5-9B/4B/2B/0.8B |

### 5.2 rate 序列（最核心改动）

| | 原版 | 本次 |
|---|---|---|
| 结构 | **全局唯一** `BENCH_CASES`（18 cases），**所有模型共用同一套 rate** | **per-model**：每个模型一套独立 rate 序列（14~59 cases 不等） |
| 来源 | 脚本里写死的一组 | 按各模型从 sglang release 文档对应档位定制 |
| 原版 18 cases | `2k/1k`: 3.0/3.2/3.4 · `3k/1k`: 2.0/2.2/2.4/2.6 · `3.5k/1k`: 2.0/2.2 · `4k/1k`: 1.0~2.0 · `4k/1.5k`: 1.0/1.2/1.4 | 见第四节各模型明细 |

> 改动动机：原版固定 rate 对慢模型（14B）必过载、对快模型（0.8B）又测不到拐点。per-model 才能各自落在有意义的区间。

### 5.3 服务启动参数（per-model extra_args）

| 参数 | 原版 | 本次 | 动机 |
|---|---|---|---|
| `--max-num-seqs` | **未设**（用 vllm 默认，实测被压到 ~60-73 并发） | **全部 8 模型设 256** | 对齐 sglang `--max-running-requests 256`，解开并发瓶颈 |
| `--speculative-config` | **未设** | **两个 8B 加 EAGLE3**（num_spec_tokens=3） | 对齐 sglang 开的投机解码 |
| 其它启动参数 | TP=1 / 显存 0.8 / block 64 / compilation-config | **完全不变** | — |

### 5.4 压测端固定参数

| 参数 | 原版 | 本次 |
|---|---|---|
| num-prompts / warmup-requests / burstiness / random-range-ratio | 100 / 500 / 102 / 1.0 | **完全不变** |
| warmup 覆盖 | 仅每 case 自带 warmup | **新增**：正式压测前对每种输入形状各预热一遍（修「每档第一个 case 偏慢」） |

### 5.5 编排层（非参数，附带说明）

新增顶层 `auto_bench.py`：参数文件驱动（环境变量注入 `run_list`/`test_list`）、结果归档到 `run_<时间戳>/` 不覆盖、ASCII 进度表、log 监控。原 `run_list.py`/`test_list.py` 改为可读环境变量，不设时行为与原版一致（向后兼容）。

> 小结：**真正影响测试结果的参数改动只有三类** —— ① rate 从全局固定改 per-model；② 加 `--max-num-seqs 256`；③ 两个 8B 加 EAGLE3 投机。其余（启动参数、压测端固定参数）与原版一致。
